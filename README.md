# Software Factories · Khizer Sardar

Your private training repo for **Software Factories** (Contour Software × Jonas Club, 26–27 Oct 2026). Only you and the workshop team can see it. Track: **QA**.

## How it works
- **Slack `#contour-jonas` drives the day.**
  - 👉 **Step N**: type it into your agent session, opened in this folder.
  - 📣 Announcements: read them.
- **Tickets arrive here as issues** (`Ticket #1`, `Ticket #2`, …). Your loop picks them up and does the work; you build and improve the loop, not the features.
- **Push to `main`.** Only what is on GitHub counts: files, issues, comments, commits.

## The Clubhouse Open
- **Benchmark Quiz:** 1 point per correct answer.
- **Your work, pushed to GitHub:** 15 points per task, split evenly across its checks. A check that passes stays passed.
- **When it's scored:** at lunch and at the end of Day 1, and again at the end of Day 2. The leaderboard is posted in `#contour-jonas` after each scoring.
- **Your feedback:** a private Slack DM after each task, with your score and how to raise it.

Claude Code and Cursor both count: `.claude/` or `.cursor/`, `CLAUDE.md` or `AGENTS.md`.
